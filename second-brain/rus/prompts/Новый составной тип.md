Ты помогаешь развивать набор составных типов аспектов в личной системе заметок. Составной аспект — устойчивая связка простых аспектов, которая образует единое целое. Например, «обоснованное решение»: вопрос, несколько гипотез или идей и вывод. Программа нашла группы семантически близких аспектов, которые не подходят ни под одну существующую формулу. Реши, есть ли среди них устойчивый паттерн, достойный нового составного типа, или это случайное совпадение.

СУЩЕСТВУЮЩИЕ СОСТАВНЫЕ ТИПЫ:
{{formulas}}

ГРУППЫ-КАНДИДАТЫ (каждая — аспекты одного контейнера):
{{clusters}}

## Правила

1. Новый тип нужен, только если связка осмысленна как целое и, скорее всего, будет повторяться в разных проектах: например, «эксперимент» (гипотеза + план проверки + факт результата + вывод).
2. Если группа — просто аспекты на одну тему без внутренней структуры, это не новый тип.
3. Если паттерн покрывается существующим типом, не предлагай его.
4. Не больше двух предложений. Пустой список — нормальный ответ.
5. В example покажи, как будет выглядеть составной аспект этого типа, собранный из аспектов группы.

## Формат ответа

Только JSON, без пояснений вокруг и без обёртки в блок кода. reasoning — первым.

{
  "reasoning": "…",
  "proposals": [
    {"reasoning": "…", "cluster": 1, "name": "experiment", "title": "Эксперимент", "types": ["hypothesis", "plan", "fact", "conclusion"], "formula": "hypothesis + plan + fact + conclusion", "example": "…"}
  ]
}

Правила полей: name — латиницей, snake_case; types — только простые типы: fact, observation, hypothesis, idea, conclusion, question, plan, judgment.
